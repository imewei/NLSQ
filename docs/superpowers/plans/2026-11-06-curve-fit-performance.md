# curve_fit / curve_fit_large Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut warm end-to-end time of `curve_fit` (n < 100k) and default `curve_fit_large` (n >= 100k) by removing measured fixed overhead, without changing results beyond the benchmark cost gate.

**Architecture:** Phase 0 measures what the spec could only estimate and sets thresholds and go/no-go gates. Workstream A shrinks per-call and per-iteration overhead in the TRF path (model key, scalar syncs, small-matrix SVD placement, bounded step selection). Workstream B shrinks per-chunk overhead in the chunked GLS path (shuffle gather, chunk covariance, SSR re-evaluation). Every change lands behind unchanged public signatures and is judged by an interleaved before/after harness run.

**Tech Stack:** Python >= 3.12, JAX (float64), NumPy, pytest (+xdist), the in-repo harness `benchmarks/compare/run_library_comparison.py`.

**Spec:** `docs/superpowers/specs/2026-11-06-curve-fit-performance-design.md` (read it first; this plan implements it, including owner decisions D1-D3).

## Global Constraints

- Python >= 3.12; float64 throughout (`JAX_ENABLE_X64=1`); model functions use `jnp`, not `np`.
- Results stay within the harness cost gate: final cost within rtol 1e-6 of the best library; `make verify` stays green (ruff, mypy, pytest).
- No new public API, no new required arguments, no changed defaults. Internal-only options only.
- Covariance semantics unchanged for every caller of `curve_fit` (`absolute_sigma`, rank-deficient `inf` covariance, NaN-in-J gives all-`inf`, never all-zero). The one allowed change is owner decision D1: per-chunk covariance on the chunked path (Task 9).
- Tests that spawn subprocesses, create arrays > 100K elements, or build Qt widgets need `@pytest.mark.serial`; run those with `-n 0`.
- Timing noise on this laptop is up to ~50% between sessions: a claim needs an interleaved before/after run in one session, judged by the `ab_nlsq` acceptance rule (ratio outside the arms' in-session spread and inside the task's bound). Comparisons across sessions need a gap above 1.5x unless a profile attributes it to the removed cost.
- Environment: the project `.venv` currently holds JAX 0.12.0.1 with the cuda13 plugin (not 0.9.x), so first check whether it sees the GPU outside the sandbox; if it does, it replaces the isolated GPU venv. Behavior on the older JAX versions that `pyproject.toml` still allows (>= 0.8.0) is not tested by this plan.
- GPU runs use the project `.venv` if it sees the GPU, otherwise the isolated venv: `uv venv --python 3.13 $SCRATCH/gpuenv && VIRTUAL_ENV=$SCRATCH/gpuenv uv pip install -e . "jax[cuda13]==0.12.0.1" jaxopt==0.8.5 optimistix==0.1.0 lmfit==1.3.4 scipy==1.18.1`; the sandbox bypass is needed for anything touching the GPU. CPU results are also checked with `JAX_PLATFORMS=cpu`; no slowdown allowed there.
- Work on branch `perf/curve-fit-small-and-large` off `main`. One task = one reviewable change. Do not stage `uv.lock` (already modified in the working tree). Commit only if the owner has asked for commits; otherwise end each task with the staged diff stat.
- Routing fact (verified, `nlsq/streaming/specs.py:243-247`): default `curve_fit_large` uses the in-memory strategy (the `curve_fit` path) below 1,000,000 points and `_fit_chunked` from 1,000,000 up. Workstream A therefore covers n < 1M through both entry points; workstream B covers n >= 1M only.

## Review Focus

Failure modes the spec implies that no benchmark exercises, most likely first. Each has a pinning test in the owning task.

1. A model whose output depends on a module global, a captured object, or a bound method's `self` state changes between two `curve_fit` calls: must not reuse the earlier wrapper (Task 3).
2. Rank-deficient or NaN-containing Jacobian at the solution: partial rank deficiency keeps its finite pseudoinverse covariance with no warning, fully degenerate or non-finite Jacobians keep all-`inf` with the same warning, on the host-SVD and Gram paths; degenerate subspaces are compared by projector and covariance, never by singular-vector signs (Tasks 5, 9).
3. Chunk contents, sigma alignment, 2D `xdata` and float32 input stay identical to the pre-change permutation, and the padded last chunk still gathers a valid row (Task 6).
4. Robust loss (`soft_l1`, `huber`), `nan_policy="omit"` and other row-dropping options: SSR reuse falls back to the old computation (Task 7).
5. Bounded fit with parameters on an active bound and tied step candidates: the same step as today, including strict-comparison tie-breaking (Task 8).
6. Non-finite residuals after a trial step: the retry path (`Delta = TR_REDUCTION_FACTOR * step_h_norm`, no termination check) is unchanged by the fused acceptance scalars (Task 4).
