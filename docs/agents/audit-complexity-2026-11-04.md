## Authorized synthesis implementation

Implemented the small, behavior-preserving cuts: removed the unused `_prepare_chunked_data` method; removed the duplicate allocation and hit-rate tests from `test_benchmark_memory.py`, retaining their canonical cases in `test_benchmark_cache.py`; derived configuration serialization fields from `fields(GlobalOptimizationConfig)`; and made `test-parallel`/`test-all-parallel` aliases of `test`, retaining `test-all-parallell`. Make help now describes the configured two workers and pre-commit hook correctly. The removed allocation benchmark's `phase2_lru` group is retired; the retained canonical allocation benchmark keeps its existing group metadata.

Serialization parity checks showed that the original methods serialize shallow values and omit fields added by dataclass subclasses. Therefore the implementation uses direct `getattr` with the base class's fields, rather than the audit's proposed `asdict(self)`/`fields(cls)`, which would change those behaviors. Field order, `_preset`, unknown-key filtering, subclass construction and shallow value identity are preserved.

Baseline verification found two failures in the canonical and duplicate LRU hit-rate tests: they probed pool keys with the scalar class `np.float64`, while production keys use `np.dtype(np.float64)`. Corrected the six retained direct pool probes across both benchmark files; the standalone LRU/FIFO simulations keep their original internally consistent keys. Production allocation behavior was unchanged.

Measured against snapshots immediately before these synthesis edits, the five changed implementation/test/build files contain **12 added and 190 deleted lines (net -178)**: adaptive helper -84 including its separating blank line, duplicate benchmark methods -69, configuration -18, Makefile -7, and canonical benchmark key corrections with no line-count change. These counts exclude this report and all pre-existing edits made by other review work.

QMC evidence: 64-point Sobol/Halton sequences exactly matched SciPy at dimension/skip pairs (1, 0), (3, 5), (20, 31), and 1,024 Halton points matched at dimension 20/skip 101. However, legacy `sobol_sample(4, 2, -1)` returns shape (3, 2), while SciPy's negative fast-forward raises `OverflowError`; legacy `halton_sample(4, 2, -2)` begins with two zero rows, while SciPy rejects a negative fast-forward with `ValueError`. Preserving these existing accepted inputs needs compatibility branches or a validation/API decision, so the proposed wholesale native replacement is rejected, not left as an unverified implementation task. JAX LHS RNG behavior is untouched.
